# Murhmurh
AI-Powered Tool to Help Humans learn new Ideas, Skills, Subjects and Acquire New Knowledge.

Murhmurh Prioritize Techniques of Manufacturing Attention, Immersiveness, and Intuition as the Core Strategy to Develop Cognitive Ability for the Learner around the Subject, Skill, Idea or Knowledge being Acquired using the Tool.

Murhmurh is implemented in several Modules as follows;

## sp-quiz
Spaced Repetition quizzing module.

Schedules quizzes and tests learners for maximum retention along their retention curve that the module adapts to.
